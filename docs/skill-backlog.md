# Skill Backlog

The repo should grow through small adjacent skills, not one larger workflow.

## Priority 1: CI Doctor

Inspect failing PR checks, fetch logs, classify failures, reproduce locally when
possible, state a root-cause hypothesis, fix, verify, push, and comment.

## Priority 2: Handoff Pack

Generate a paste-ready continuation prompt from live repo state: path, branch,
worktree, PR, issue, checks, changed files, verification evidence, blockers, and
next commands.

## Priority 3: Orient Codebase

Read local guidance, README, manifests, test configuration, entry points, branch
state, and likely verification commands before implementation starts.

## Priority 4: Verification Gate

Map a diff or PR to Light, Standard, or Thorough verification; run or list exact
checks; produce an evidence ledger.

## Priority 5: Worktree Doctor

Inspect, create, sync, and clean up task worktrees safely.

## Priority 6: Team Review

Spawn bounded review lanes for correctness, tests, architecture, security,
performance, and docs when delegation is authorized.

## Priority 7: State Ledger

Maintain a compact current-state artifact for long-running sessions and
handoffs.
